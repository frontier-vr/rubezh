# Форма обратной связи для другой команды

Заполняет каждый участник Рубежа после того, как прошёл VR-проект другой команды (`NG-22`, `MM-16`),
и отдаёт команде в тот же день. Оценки 1–5: 1 — плохо, 5 — отлично. Пишем по делу: что видели,
где это было, что предлагаем. Ответы копируем в [`playtest-external.md`](playtest-external.md).

## Шапка

| Поле | Ответ |
|---|---|
| Проект / команда | |
| Кто проходил | |
| Дата, шлем, сборка (APK / редактор) | |
| Сколько минут заняло прохождение | |
| Прошёл до конца? Если нет — где остановился | |

## Оценки

| № | Вопрос | 1–5 | Комментарий |
|---|---|---|---|
| 1 | Понятно, что делать в первые 30 секунд | | |

| 7 | Модели и окружение: масштаб верный, ничего не мерцает и не проваливается | | |
| 8 | Плавность: нет рывков и подвисаний | | |
| 9 | Цель проекта достигнута: научился / понял то, что задумано | | |

## Открытые вопросы

1. Что было самым неудобным? Где именно?
2. Где застрял или сделал не то, что задумано? Что подсказало бы правильное действие?
3. Что точно нужно оставить как есть?
4. Баги: что произошло, где, как повторить (по строке на баг).
5. Одна вещь, которую стоит поменять до защиты.
