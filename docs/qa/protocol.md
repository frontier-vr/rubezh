# Протокол ручной проверки в шлеме (NG-19)

Прогоняем всей командой на Quest 2 со свежим APK, каждый — свою колонку. Строка отмечается, когда
поведение совпало с «Ожидается»; не совпало — Issue с меткой `bug` (и `core` / `xr` / `ui` / `art` /
`ux` по месту), номер — в колонку «Баг».

Перед шлемом то же самое проверяют автотесты (колонка «Автотест»). Главный — **сквозной прогон**
`FullRunTests`: всё упражнение в `Main.unity` руками XRI (захваты, сокеты, телепорты, команды
оружия) от шкафа до шкафа, с осечкой или прихватом, экраном результата и «Повторить». Он нашёл два
бага логики (#163, #164) до первого запуска в шлеме; после исправления (`VP-16`) — `Passed 100`,
4/4 попаданий, нарушений нет.

Статус на 16.10: **автоматическая часть пройдена** (EditMode 225, PlayMode 116), **в шлеме не
прогоняли** — нет APK (`NG-01` ждёт Unity 6000.3.24f1 с Android) и шлема.
