# Референсы: оружие и снаряжение

Референсы для моделей Маши: пистолет (`MM-05`, `MM-07`), магазин, патрон и гильза (`MM-06`,
`MM-08`), мишенный механизм (`MM-10`), наушники и очки (`MM-11`). Картинки в проект не
импортируются: они только для моделирования. Если что-то отсюда попадёт в проект как ассет,
строка — в [`CREDITS.md`](../../CREDITS.md).

Правила отбора (ТЗ проекта):
- пистолет **обобщённый**: без узнаваемых торговых марок, надписей и логотипов. Реальные модели
  берём только ради пропорций и устройства;
- мишень только **спортивная круговая**, без силуэтов человека;
- эстетика спортивно-техническая: без камуфляжа и военной символики.

Ракурсы: у каждого объекта минимум три — сбоку, сверху или спереди, три четверти.
3D-модели на Sketchfab вращаются в браузере и закрывают все ракурсы сразу.

длина ~190 мм, высота ~135 мм, ширина ~30 мм, ствол ~110 мм, ход затвора ~45 мм.
