# Финальная презентация (YG-15, защита 18.12)

`rubezh-final.pptx` (и `rubezh-final.pdf` для просмотра) — 14 слайдов, у каждого участника свои:

| Слайды | Кто | Что |
|---|---|---|
| 1–3 | вся команда | идея, цифры упражнения, девять шагов |
| 4–6 | Юля | комната до и после, откуда взялись решения, подсказки и экран результата в шлеме |
| 7–9 | Маша (`MM-16`) | что смоделировано, иерархия и подвижные части, проверка сеток — `docs/defense/models.md` |
| 10–11 | Влад (`VP-18`) | механика детекторов, почему в сцене нет людей, повтор — `docs/defense/detectors.md` |
| 12 | Никита | сборка, тесты, протокол |
| 13–14 | вся команда | как менялись решения, итог |

Заметки докладчика — в каждом слайде. Колода собирается скриптом из картинок `docs/img` и
`docs/renders`, цвета — `docs/palette.md`:

```bash
npm install pptxgenjs
node tools/docs/final_presentation.js
```
