# Рендеры моделей для презентации (MM-15)

Модели сложной формы — пистолет и мишенный механизм. На каждую два кадра: чистый вид и сетка
с оверлеем Statistics (число треугольников) — то же показываем на защите в Blender.

| Модель | Чистый вид | Сетка и Statistics | Треугольников | Бюджет |
|---|---|---|---|---|
| Пистолет (`MM-07`) | [pistol.png](pistol.png) | [pistol_wire.png](pistol_wire.png) | 2 338 | 8 000 |
| Мишенный механизм (`MM-10`) | [target_mechanism.png](target_mechanism.png) | [target_mechanism_wire.png](target_mechanism_wire.png) | 836 | 6 000 |

- Чистый вид — EEVEE, три источника, материал с атласом `MM-13` (лист мишени — своя печать `MM-12`),
  1600 × 1000. Мишенный механизм в кадре — каретка с рамкой и листом, направляющая 8,8 м уходит вдаль.
- Сетка — окно 3D-вида Blender 5.1: заливка Solid, оверлей Wireframe и Statistics; Statistics считает
  всю модель (у механизма — вместе с направляющей и тросом).
- Пересобрать: `tools/blender/renders.py` — `run()` пишет чистые кадры, `wire("<имя>")` готовит окно
  для снимка сетки (View → Area → Screenshot Area). Исходники `.blend` скрипт не сохраняет.
- Если после плейтеста `MM-14` модель поменяется — перерендерить.
