# Сценарий инструктора

Тексты, которые говорит и показывает инструктор: команды по фазам, подсказки по шагам и причины
грубых нарушений для стоп-экрана. Машиночитаемая копия для кода — `Assets/_Rubezh/Data/Hints/script.ru.json`
(файл и этот документ меняются вместе). Правила, *когда* показывать подсказку, — `YG-08`.

## 1. Тон

- Инструктора в сцене нет: он **голос** (`YG-13`, группа микшера Voice — наушники на неё не
  действуют) и **табло команд** у рубежа (`VP-24`). Фраза команды держится на табло всю фазу.
- Нейтрально-технический тон, без оценок и без «вы»: «ствол вне сектора», а не «вы опять
  нарушили». Команды — коротко и в повелительном наклонении, как на настоящем рубеже.
- Подсказка — формат `<кнопка>: <действие>`. Кнопка подставляется по руке: `{Eject}` — A справа,
  X слева; `{Safety}` — B справа, Y слева; `Grip` и `Trigger` одинаковые на обеих руках.

## 4. Причины грубых нарушений (стоп-экран FR-39)

Стоп-экран показывает заголовок и одну строку пояснения по `ExerciseResult.FailReason`.

| `Violation` | Заголовок | Пояснение |
|---|---|---|
| `MuzzleOutOfSector` | Ствол вне сектора | Заряженное оружие дольше 1,5 с было направлено вне мишенного коридора. |
| `LookIntoMuzzle` | Взгляд в ствол | Взгляд был направлен в дульный срез оружия. |
| `ShotBeforeFire` | Выстрел до команды «Огонь» | Выстрел произведён до команды «Огонь». |
| `ShotAfterCease` | Выстрел после команды «Стой» | Выстрел произведён после команды «Стой». |
| `ShotOutOfSector` | Выстрел вне сектора | Выстрел произведён в направлении вне мишенного коридора. |

## 5. Тексты остальных нарушений

Мелкие нарушения грубыми не бывают; для них — короткие названия у контроллера и на экране
результата (13 названий, `YG-08`). Отдельных текстов стоп-экрана у них нет: `FingerOnTrigger`,
`NoEarmuffs`, `NoGlasses`, `StepOrder`, `IncompleteInspection`, `ReturnedLoaded`, `CasingLeft`,
`JamMishandled`.
