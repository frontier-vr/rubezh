# Палитра проекта

Выведена из мудборда окружения ([`design-doc.md`](design-doc.md) §6, картинки — `docs/moodboard/`).
Нужна, чтобы атлас оружия (`MM-13`, Маша) и атлас окружения (`YG-12`, Юля) не спорили по цвету, а
цвета интерфейса не путались между собой. Эстетика спортивно-техническая: бетон, металл, жёлтая
разметка; никакого камуфляжа. Прозрачности нет ни у одного цвета.

## Окружение

| Цвет | Роль | Где |
|---|---|---|
| `#8E8D88` | бетон стен | стены зала и коридора |
| `#66675F` | бетон пола | пол зала, пол коридора |
| `#C9C7C0` | штукатурка | потолок, светлые панели |
| `#4B535B` | крашеный металл | щиты коридора, шкаф, стойка рубежа, полка СИЗ |
| `#A3AAB0` | светлая сталь | пулеулавливатель, светильники, кронштейны |
| `#F2C200` | сигнальный жёлтый | линия огня O-29, разметка на полу, рамки табличек |
| `#ECEAE4` | белая краска | поле табличек, **контуры мест** на столешницах |
| `#1D2228` | графит | текст табличек и табло |

## Интерфейс и состояния

Каждый цвет — одна роль на всё приложение. Различаются не только цветом: у подсветки — пульсация,
у метки финиша — надпись, у грубого нарушения — значок и слово.

| Цвет | Роль | Где |
|---|---|---|
| `#1FB6C9` | **подсветка подсказки FR-26** | пульсирующая подсветка следующего объекта и метки якоря (`VP-21`) |
| `#3E9E4F` | метка финиша | статичный контур в O-05 и надпись «Сдача оружия» (`YG-11`) |
| `#D23A2A` | стоп и грубые нарушения | стоп-экран, грубые строки экрана результата |
| `#3E9E4F` · `#F2C200` | вердикты «зачёт» и «зачёт с замечаниями» | значки ✓ и ! на экране результата ([`result-screen.md`](result-screen.md)); жёлтый в интерфейсе — только предупреждение |
| `#101418` | фон табло и экранов | табло команд O-31, экраны R1–R3 |
| `#F2F0EA` | текст на тёмном | табло, выноски у контроллера |

Подсветка FR-26 отличается от жёлтой разметки, красного, белых контуров мест и зелёной метки
финиша — требование `VP-21` и `YG-08`.
