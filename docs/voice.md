# Озвучка инструктора

Голос инструктора (`YG-13`) — 43 коротких клипа в `Assets/_Rubezh/Audio/Voice/`: команды фаз, подсказки и
причины грубых нарушений. Клипы собираются из текстов сценария синтезом речи, вручную не записываются.

| Что | Где |
|---|---|
| тексты фраз | [`script.md`](script.md) §2–4 → `Assets/_Rubezh/Data/Hints/script.ru.json` |
| генератор клипов | `tools/audio/voice_silero.py` |
| клипы | `Assets/_Rubezh/Audio/Voice/<ID>.wav`, 24 кГц, 16 бит, моно, в Git LFS |
| кто их играет | `Code/Gameplay/InstructorVoice.cs`: имя клипа = ID фразы; список клипов — на объекте `Exercise/InstructorVoice` в `Main.unity` |
| проверка, что клип есть у каждой фразы | тест `VoiceCoverageTests` |

## Голос

Нейросетевой синтез [Silero TTS](https://github.com/snakers4/silero-models), модель `v5_ru`, диктор `xenia`.
Работает на своём компьютере без сети (кроме первой загрузки модели, около 140 МБ) и без видеокарты:
все клипы собираются за несколько секунд. Раньше стоял голос Windows «Microsoft Irina» — звучал машинно,
на плейтесте его просили заменить (`decisions.md`, Р-12).

Лицензия модели — CC BY-NC-SA 4.0: только некоммерческое использование (`CREDITS.md`).

## Пересобрать клипы

После правки текстов в `script.md`:

```bash
python tools/docs/script_to_json.py      # script.md → script.ru.json
pip install torch numpy                  # один раз
python tools/audio/voice_silero.py       # все клипы
```

Одна фраза или другой диктор:

```bash
python tools/audio/voice_silero.py --only cmd_fire hint_chamber
python tools/audio/voice_silero.py --speaker eugene     # aidar, baya, kseniya, eugene, xenia
```

Имена файлов не меняются, поэтому `.meta` и ссылки в сцене остаются прежними. Новая фраза — новый файл:
его надо добавить в список клипов `InstructorVoice` в `Main.unity`.

## Что звучит

- Команда — текст целиком: «Контрольный осмотр: отделить магазин, затвор на задержку».
- Подсказка — только действие после двоеточия: из «`{Safety}`: снять с предохранителя» звучит «Снять с
  предохранителя». Кнопка зависит от руки и видна у контроллера.
- Причина грубого нарушения — «заголовок. пояснение».
- Тексты табло над столами (`script.md` §6) не озвучиваются.

## Если фраза звучит не так

Всё правится в начале `tools/audio/voice_silero.py`:

- **Ударение.** Словарь `STRESS`: слово или словосочетание как в сценарии → оно же с `+` перед ударной
  гласной (`"к шкафу": "к шк+афу"`, `"в шкафу": "в шкаф+у"`). Остальные ударения модель ставит сама.
- **Цифры, сокращения, кавычки.** Список `SPOKEN`: что заменить перед синтезом (`"1,5 с"` → `"полутора
  секунд"`). Цифры модель не читает — пишите числа словами или добавляйте замену.
- **Громкость и паузы.** `PEAK` — пик после нормализации, `PAD_SECONDS` — тишина в начале и конце клипа.

После правки пересоберите нужные клипы через `--only` и послушайте их в Unity.
